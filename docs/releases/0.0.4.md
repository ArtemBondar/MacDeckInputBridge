## What’s new

- **Use your Mac trackpad or mouse on the Deck.** Enable experimental pointer forwarding in MacDeck settings, then use Control–Shift–F12 to switch the keyboard and pointer together. Supports movement, left/right click, dragging, and two-finger scrolling in Steam Deck Desktop Mode.
- **More responsive pointer forwarding.** The first movement sends immediately, continuous movement is batched more frequently, and queued movement is combined during congestion while preserving clicks and keyboard event order.
- **A clearer Accessibility setup.** MacDeck registers its first permission request even when System Settings is already open. Later attempts bring the Accessibility page forward instead of requesting another popup.
- **Refreshed website and documentation.** Updated illustrations, branding, favicon, setup copy, and README banner.

## Before updating

- Install the Mac and Steam Deck apps from this same release. Pointer forwarding is optional and off by default; keyboard-only use remains available.
- Pinch and macOS system gestures stay on the Mac. Two-finger scrolling is forwarded to the Deck and also remains available on the Mac. Gaming Mode pointer support is outside this release’s scope.
- macOS requires Accessibility permission. The Mac app is ad-hoc signed and not notarized; if macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway**. Steam Deck installation and non-root `/dev/uinput` setup instructions are included in its archive.

## Verification

Swift, locked Rust, app-bundle, and installer checks run before publication. The owner confirmed pointer forwarding works on their Mac and Deck. Exact end-to-end latency, the complete failure-recovery hardware checklist, and the updated Accessibility window flow still require physical-device verification.
